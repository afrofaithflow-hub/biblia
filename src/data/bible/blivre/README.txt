Format: one JSON file per book, named with BiblePath book ids.
{"n": "<book name>", "c": [{"d": "<psalm title, optional>", "v": ["verse 1", "verse 2", ...]}]}
Verse i + 1 is v[i]. An empty string "" marks a verse the translation leaves out.

Changes from the source: footnotes, cross references, section headings and
markup removed; spacing and punctuation repaired; a few misplaced verse
breaks corrected. The words of the translation are otherwise unchanged, except for these corrections of typos in the source:
- Acts 17:24 "tempos" corrected to "templos" (Acts 7:48 and the Greek read "temples").
